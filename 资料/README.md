- 页码以 PDF 文件第一页为第 1 页；原卷印刷页码、答案编号可能与之不同。讲题先打开对应页核对题干和图示。

- 已整理题型和代表设问，未逐题重新作答或验证所有参考答案。原稿中发现的选项、分值、题号、重复页及答案不完整问题，已逐项记录到相关学科档案。
- 本包没有听力音频；英语听力题干或答案不能代替有音频支持的听力实测。历史选择题 Word 未附答案页。
- 华宜、武珞路语文卷与单篇《断更朋友圈之后》有同文同题，重复做可复习，但不算新的迁移诊断。手写数学解答的作者及权威性未确认，不记为本人答卷。
- 已审页面未发现需处理的学生身份填写信息；阅读/范文人物姓名不作为本人身份。尚未逐字校勘全部试卷，实际诊断仍以用户将提供的本人试卷为准。
