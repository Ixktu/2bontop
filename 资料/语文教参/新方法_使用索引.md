# 新方法语文中考教用：使用索引

来源：[用户提供的文字整理版](<../原始资料/语文教参/新方法语文中考教用_文字整理版.pdf>)，277页，2027版教师用书。当前已阅读方法说明，并挑选代表题建立索引；未逐题刷完，未全面校订参考答案。

**使用方式：先定位你当题的卡点，再推荐1—2道训练同一能力的题，附篇名、题号、实际PDF页和推荐理由。可只练概括、证据定位、审题一句话或一个段落，不默认做整篇整卷。**

当前PDF页码必须按本文件实际页序定位。书中写的“PDF第…页”是旧扫描源页标签，“书内页码/书页”是另一套标签。合并、拆分、补文和重复页使偏移量不固定，不能用纸书页数直接跳转。

## 整理版的使用限制

- 这是文字整理版，原始扫描件未到；若题面、选项、答案、段号或字词矛盾，先核对清晰来源，不能把转写错误当用户失分。
- 实际81页出现选文与题答错配；133页断句选项重复；137页题1答案字母矛盾；143—144页有跨篇题目；146—147页内容不清，相关题暂不作为独立判分题。详细情况保存在JSON。
- 语言运用部分有省略正文/选项、字音字形原样与“勘误”相同等情况；不把所有转写内容做成必背表。也不采用“生僻注音默认正确”之类猜题经验作为通则。
- 写作188页解释与材料错位；204—205、235—237、246—247有重复；综合卷卷首/作文有缺失或跨章补文。按同一题去重，不以重复次数计算练习量。
- 教参关于题型、书目及当地命题的判断需要对照当年要求；学习范围不限于本书。书中“2分一要点”等经验不覆盖用户明确的按原文逻辑组织答案要求。
- 大部分作文题写“不少于600字”；历史任务“700字以内”仅属当次例文生成要求，不是通用考试上限。
- 本书是方法与选题库，未改变本人掌握度或成绩记录。文言部分是文本训练，不等同于历史要求的完整多义词/虚词背诵单。

## 后续推荐流程

1. 先读用户原题和本人尝试，判断卡点属于审题、定位、归并、逻辑、表达还是运算/字词基础。
2. 用索引筛选1—2题，打开指定PDF页复核全文、选项和题号，避开已标注的错配题。
3. 推荐时说明“练什么”和与当前题的对应之处，按用户要求给微弱提示或完整讲解。
4. 依据本人新作答更新语文档案；只读过参考解答不记作独立掌握。
