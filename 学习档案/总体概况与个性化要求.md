## 个性化要求与辅导约定

### 用户明确表达过的偏好

1. 讲题按当前请求控制信息量。数学多次要求“微弱的提示”“别给完整答案”；明确要求答案时直接给出。
2. 练习可一题一题进行；题目要典型、接近实际题目规模，避免用过短或过于直接的素材代替所需训练。
3. 语文阅读每个答案点要有原文依据；答案结构遵循原文的并列、转折、递进、因果等关系。后来明确修正了“4 分必为两点、6 分必为三点”的机械规则，以后采用修正后的要求。
4. 英语范文连贯、有逻辑、详略得当，长短句和词汇有变化；少量出彩表达，自然、不拗口、方便背诵，避免公式化堆砌。
5. 资料以内容为主，少放无用副标题或说明。打印资料要重视字号和实际可读性；曾将过密的英语资料改成四页。
6. 化学现象希望解释原因，便于理解性记忆；道法按“材料/设问 → 可选知识点 → 结合材料作答”整理。

### 本档案采用的工作方式（可随用户反馈调整）

- 每次学习先读本文件，再读相关学科文件；用户的新要求优先于旧偏好。
- 默认先确认当前任务和卡点，再给一个可执行的小步骤；避免反复询问已记录的信息。
- 批改时区分概念、审题、条件识别、方法选择、运算、表达与时间问题，保留用户原答摘要和可观察证据。
- 一次学习结束后，将有用的新事实、已完成练习、仍未解决的问题和下次接续点写入相应文件；总文件只同步跨科信息。
- 掌握度使用“未评估 / 需提示 / 可独立完成 / 换情境仍能完成 / 隔日复测保持”。听懂解释和看过答案不自动算掌握。
- 事实、用户自评、辅导者的暂定判断分开记录；暂定判断写明依据与待验证项。历史 AI 的答案不作为权威知识来源，使用前重新核对题目和条件。
- 日期用北京时间。考试日期确认前不安排精确倒计时；学习时间明确前不强行制定每日高负荷计划。
- 这些文件是可维护的学习记录，不保证聊天上下文永久完整；新会话应主动读取。仓库根目录 README 提供入口，提交与上传情况以 Git 记录和远端状态为准。
